# GlazeWM Notes
## Important Warning
1. Before using GlazeWM, must turn off the window center opening feature in MyDockFinder
- This conflict will cause window positioning bugs and tiling failure
- This feature is disabled by default in our backed-up MyDockFinder.ini config, no manual adjustment needed after config restore
## Config File Path
Default local config storage location:
C:\Users\USERNAME\.glzr\glazewm
Replace USERNAME with your local Windows user folder name
